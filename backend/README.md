# Astrology Consultation Backend

Production-oriented MERN backend scaffold for an astrology consultation app.

## Key Modules
- OTP login for users
- Guest login for users
- Razorpay payments and wallet recharge
- Socket.io realtime layer
- Firebase FCM notifications
- Cloudinary file uploads
- Admin management, analytics, coupons, refunds, invoices, horoscopes

## Run
1. Copy `.env.example` to `.env`
2. Install dependencies
3. Start MongoDB
4. Run `npm run dev`
